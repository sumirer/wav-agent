# UI 提示音体系

## 设计原则
一套 UI 音效必须"听起来像一家人"：**统一使用同一个基音音阶、统一的时长区间、统一的收尾方式**。
用户点一次就知道是同一个产品。

- 统一基准：所有提示音都基于同一个调（推荐 C 大调，即 261.6 / 329.6 / 392.0 / 523.3 / 659.3 / 784.0 Hz）。
- 统一时长：点击 0.08~0.15s，切换 0.15~0.25s，成功 / 失败 0.4~0.7s。
- 统一质感：`waveform` 统一用 triangle 或 sine，避免 pop 感；统一加一点点 bitcrush（10~12）获得轻微的"电子"统一色。
- 音量感：成功 > 点击 > 警告 > 失败，用 amplitude 表达优先级。

## 语义映射
| 场景 | 音高走向 | 结构 |
| --- | --- | --- |
| 点击 / tap | 单音，不动 | 一个 0.1s 的 C5 |
| 切换 / toggle | 上行二度 | C5 → D5，间隔 60ms |
| 成功 | 上行三音琶音 | C5 → E5 → G5，每音错开 50ms，最后一个音长一点 |
| 警告 | 重复同音两次 | E5 两个 60ms 脉冲，中间留 70ms |
| 失败 | 下行小二度 | A4 → G#4 快速下滑，加 lowpass 900 让它变闷 |
| 通知 | 上行四度 + 尾音 | G5 → C6，第二个音带一点 reverb |

## 实现要点
- 每个音符就是一个 layer，用 `startTime` 错开，用 `amplitudeCurve: [[0,0],[0.01,1],[0.9,1],[1,0]]` 做软起软落。
- 不要使用强 attack 的 square，会有明显的爆音感。
- 每个音的结尾都要有 release，不要依赖 fadeOut 一刀切。
- 一组音效请**分别调用 generate_wav**，标题使用统一前缀便于用户识别，例如「UI-成功」。

## 硬性要求
- `duration` 尽量精确到 0.01s，短音不要留长尾巴。
- 单个提示音不要使用 reverb（会显得拖沓），通知类可以用 mix 0.15 的轻微 reverb。
